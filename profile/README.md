# TechShield

Free, open-source developer tools that run **100% in your browser** — no sign-up, no
tracking, and your input is never sent over the network.

Part of [MMOALL Developer Tools](https://mmoall.com/tools).

## 🧰 Tools

### JSON

| Tool | What it does | Live |
| --- | --- | --- |
| [JSON Formatter](https://github.com/techshield-tech/json-formatter) | Format, minify, validate, and sort keys | [Open](https://techshield-tech.github.io/json-formatter/) |
| [JSON Validator](https://github.com/techshield-tech/json-validator) | Precise error locations and optional JSON Schema validation | [Open](https://techshield-tech.github.io/json-validator/) |
| [JSON Diff](https://github.com/techshield-tech/json-diff) | Compare two documents: added, removed, and changed values | [Open](https://techshield-tech.github.io/json-diff/) |
